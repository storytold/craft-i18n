# WordCraft ภาษาไทย — ชุดไฟล์ให้ทีมตรวจ

ไฟล์นี้คือ **แคตตาล็อกคำแปลหน้าจอ WordCraft ภาษาไทย** จำนวน **270 รายการ**
(WORDCRAFT แสดงเฉพาะรายการที่มีอยู่ รายการที่ไม่มีจะแสดงภาษาอังกฤษ)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `WordCraft-TH-Review.xlsx` | **เริ่มจากไฟล์นี้** — ตารางคำแปล มีช่อง reviewer notes และช่อง Ver |
| `wordcraft-th-review.tsv` | ไฟล์เดียวกันในรูป TSV (เปิดใน Excel/Sheets ได้, คั่นด้วย TAB) |
| `locales/th/wordcraft.tsv` | ตัวแคตตาล็อกจริงที่จะส่งขึ้น craft-i18n (ผ่านตัวตรวจของ repo แล้ว) |
| `locales/th/craft-launcher.tsv` | แคตตาล็อกภาษาไทยของ ArtCraft Launcher (87 รายการ) |

## วิธีตรวจ

1. เปิด `WordCraft-TH-Review.xlsx`
2. ดูคอลัมน์ **Thai** เทียบกับ **English** (คอลัมน์ English คือข้อความที่แอปใช้ค้นหา — ห้ามแก้)
3. คอลัมน์ **German** เป็นข้อความเยอรมันที่แอปแสดง ใช้เทียบความหมายได้
4. ถ้าคำแปลไม่ดี/ผิดความหมาย → พิมพ์ข้อเสนอใน **reviewer notes**
5. ถ้าผ่าน → ใส่ 1 ในช่อง **Ver**

## ความหมายของ group

| group | ความหมาย | จำนวน |
|---|---|---|
| `existing` | แถวที่มีอยู่ใน pull request ที่เตรียมไว้แล้ว | 42 |
| `core` | คำศัพท์หลัก (คำสั่งพื้นฐาน ปุ่มเครื่องมือ) | 102 |
| `bulk` | ชุดคำเต็ม (คำสั่ง แท็บ รูปแบบ) — ควรอ่านละเอียด ביותר | 126 |

## ข้อสังเกต

- ชื่อรุ่นเก่า `SmartArt` / `WordArt` ตั้งใจเก็บเป็นภาษาอังกฤษ เพราะแอปใช้แทนของเดิม (ยังไม่ถูกเปลี่ยน)
- คำแปลเขียนจากความหมายภาษาอังกฤษ และใช้คำเดียวกับคาทาล็อก PdfCraft/PhotoCraft ภาษาไทยที่มีอยู่ใน repo อยู่แล้ว
- ใช้ **AI ช่วยจัดทำ** และ **ยังไม่ได้ผ่านการตรวจโดยเจ้าของภาษา** — ไฟล์นี้มีไว้เพื่อทำขั้นนั้น

## เมื่อตรวจเสร็จ

- แก้ `locales/th/wordcraft.tsv` ตาม notes
- รันตัวตรวจ: `cargo test -p craft-i18n-tests --test locales --test wordcraft_feature_names`
  (ในเครื่องนี้รันผ่านแล้ว 17 + 3)

> ข้อควรทราบจาก CodeRabbit: `wordcraft_feature_names` ตรวจเฉพาะ locale ที่อยู่ใน `LOCALES`
> (`crates/craft-i18n-tests/tests/wordcraft_feature_names.rs`) ซึ่ง**ยังไม่มี th** —
> ฉะนั้นถ้าแก้ชื่อฟีเจอร์ภาษาไทย ทดสอบนั้นยังไม่จับ ถ้าต้องการให้ครอบคลุม ต้องเพิ่ม th ใน `LOCALES`
> เป็น PR แยก ส่วน `locales.rs` ตรวจแคตตาล็อกของทุก locale รวม th แล้ว

## หมายเหตุ

แอปจะยังไม่แสดงตัวเลือกภาษาไทย จนกว่า WordCraft จะเพิ่ม `th` ในรายการภาษาเอง
(`crates/ui-egui/src/i18n/mod.rs`) — ต้องขอทีม developer
